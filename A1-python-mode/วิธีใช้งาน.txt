Processing Version: 4.4.10
Mode: Python Mode

1.เริ่มต้นหน้าจอใช้งาน (setup)
   เมื่อกดสั่ง run โปรแกรมจะเปิดหน้าจอ Canvas ขนาด 1000x600 px แสดงกระบอกปืนใหญ่ ลูกปืน และแผงสถิติด้านซ้าย

2.ปรับแต่งตัวแปร (Adjust Parameters)
   UP / DOWN :ปรับเพิ่ม-ลด มุมยิง
   LEFT / RIGHT :ปรับเพิ่ม-ลด ความเร็วต้น

3.สั่งยิงและรีเซ็ต (Launch & Reset)
   SPACEBAR :สั่งยิงลูกบอลออกไป
กด SPACEBAR ซ้ำอีกครั้งเพื่อเคลียร์เส้นวิถีและกลับจุดเริ่มต้น
